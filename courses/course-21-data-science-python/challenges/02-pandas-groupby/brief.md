The data engineering team handed you a CSV export from a legacy order system. It looks fine at first glance, but the first automated pipeline run produces NaN totals and a `TypeError` on the groupby step. Your job: load the CSV, clean it, and return a specific groupby aggregation that the hidden pytest harness asserts exactly.

## Data schema (as-intended)

| Column | Intended type | Known problems |
|---|---|---|
| `order_id` | int | some rows are `"N/A"` strings; drop those rows |
| `region` | str | mixed case (`"north"`, `"North"`, `"NORTH"` all mean the same region) |
| `amount` | float | some cells contain `"$"` prefix or commas (e.g. `"$1,234.50"`); strip and convert |
| `quantity` | int | may be float due to NaN rows that get dropped; cast after dropping |
| `date` | datetime | stored as `"YYYY-MM-DD"` strings |

## Mission

Implement two functions in `solution.py`:

### `clean(df: pd.DataFrame) -> pd.DataFrame`

Return a cleaned DataFrame where:
- Rows with `order_id == "N/A"` (or unparseable as int) are **dropped**.
- `order_id` is cast to `int64`.
- `region` is **title-cased** (so `"north"` → `"North"`, `"NORTH"` → `"North"`).
- `amount` has any leading `$` and embedded commas removed, then cast to `float64`.
- `quantity` is cast to `int64`.
- `date` is parsed to `datetime64[ns]`.

### `aggregate(df: pd.DataFrame) -> pd.DataFrame`

Accepts the **cleaned** DataFrame. Return a DataFrame with:
- One row per `region`.
- Columns: `total_amount` (sum of `amount`), `total_quantity` (sum of `quantity`), `order_count` (number of rows).
- Index reset to default integer index (call `.reset_index()`).
- Rows sorted ascending by `region`.

The hidden verifier asserts the exact numeric values of `total_amount` (within `1e-2` tolerance) and the exact integer values of `total_quantity` and `order_count` per region, using the seeded CSV generated by `setup.sh`.

## Why this matters

Real-world data is always dirty. A `groupby` on a column with mixed types raises a `TypeError`; a `sum()` on a column that is still `object` dtype silently concatenates strings. The discipline of: `read → inspect dtypes → clean → assert dtypes → aggregate` is the difference between a pipeline that works once and one that works at 3 AM.
